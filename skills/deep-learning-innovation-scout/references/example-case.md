# 示例：医学分割卡住后怎样得到有依据的思路

这是演示流程的虚构条件，不是用户当前项目或真实实验结果。

输入：“我做2D医学分割，平均Dice上不去了，细小结构和边界经常断，单卡24GB，想找论文思路。”

先判断：需要知道分组划分、最强基线、边界失败样例及多次实验波动。当前只能把“下采样丢细节”“尺度/频率表征不合适”“标签边界不一致”作为竞争假设。

实际检索：

```text
python scripts/search_catalog.py 医学分割 边界 小波 --limit 8
python scripts/search_catalog.py 下采样 小目标 --limit 8
```

候选A：先定位分辨率损失。保持模型不变，比较受控分辨率/裁块与下采样设置，报告细小结构、边界和较大结构分桶。若简单分辨率调整已经修复大部分问题，就先解决采样，而不是增加长程模块。

候选B：若高频结构有用但下采样后消失，检索WTConv或抗混叠相关机制。WTConv官方题名与摘要已核对，目录中出现于第14、15页；这不是它在该医学任务有效的证明。先读原文与代码，再与同预算空间卷积比较，检查边界指标及高频噪声扰动。如果收益只来自额外容量或对噪声更敏感，则削弱原假设。

候选C：若标签或伪标签边界本身不一致，考虑标注审计、置信度与一致性路线，检索DyCON或弱监督工作。对照标注预算和教师模型；不把更强教师带来的收益归给新增模块。

现在不声称三者是“新颖论文贡献”。下一步优先收集按尺寸/边界类型分组的失败样例并做候选A的便宜实验，再决定是否值得实现B或C。论文贡献还需要近期文献的机制差异核验。
