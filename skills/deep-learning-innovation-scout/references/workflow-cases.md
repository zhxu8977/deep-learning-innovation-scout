# 工作流案例：从求助到实验决定

以下是示意案例，不是已经完成的实验，没有虚构涨点数据。

## 医学分割：区域尚可但边界断裂

用户：“我用U-Net，整体Dice不算低，细小血管总断，想加注意力。”

先利用已有信息确认是断裂、位置偏移还是漏掉小结构；检查患者级划分、原始分辨率、下采样次数和标注一致性。没有失败图时先给条件化诊断，不强迫填写完整选题表。

检索“细结构 断裂”“下采样 边界”“蛇形卷积”，读Dynamic Snake Conv、HWD、DySample与相关代码接口。将三个假设分开：输入/下采样已丢信息；空间采样不适应弯曲形状；监督没有关注连通性。

先固定U-Net，只对比高分辨率简单分支与单个候选改变，评价区域、连通与虚假连接。若提高输入分辨率即可解决且预算可接受，暂选简单方案；若蛇形采样只在弯曲细结构显著改善，再核对相关原文并设计对普通DCN、条带卷积的区分实验。不能同时改注意力、损失和上采样后宣称其中一项有贡献。

## 时序预测：长序列模型没带来提升

用户：“换了Mamba还是不如原模型，怎么找创新点？”

先查时间划分、历史长度、预测步长、线性/季节朴素基线及是否存在漂移。确定“模型复杂但没增益”不是一个机制解释。

检索“时序 漂移”“周期 噪声”，分别读RevIN、FECAM和ASB/ICB。若失败集中在均值或尺度变化，优先只检验RevIN；若周期不稳定或噪声主导，先用频谱和固定滤波诊断。不要默认三个模块一起加入。

最小实验保持原模型和时间划分，只改变历史输入归一化策略，按时段和预测步长报告误差。核查norm/denorm对应同批历史统计，避免未来泄漏。收益只对均值缩放扰动成立，就把结论限定在该范围；再决定是否研究更深层语义漂移，而不是声称解决所有非平稳性。

## 遥感小目标：涨点是否只是像素预算

用户：“我把ASFF和注意力放进检测器有提升，能写成创新吗？”

先核对裁块、输入尺度、检测头、预训练、训练轮数与原图级地理隔离。以MOD机制卡和代码接口核实ASFF真正改变的层级和形状。

将假设写为“跨尺度矛盾干扰小目标特征选择”，而不是“用了多尺度所以更好”。设置原FPN、对齐后固定平均融合、学习权重融合，并保持额外像素和训练预算可比；单独做注意力分支消融。

若高输入分辨率或普通concat投影已取得同等收益，机制差异尚未成立。若学习权重只对特定尺度与复杂背景有效，继续查相关尺度选择与融合近邻工作，考虑能否解释其失效条件和成本优势。方法论文贡献待查新；工程收益可独立报告。

## 工业缺陷：数据协议优先于换模块

用户：“我有带钢缺陷数据，想做异常检测创新。”

先明确是有缺陷标签的监督定位，还是仅正常训练的异常检测。查数据索引中的NEU/Severstal等线索，核实标注粒度，不能从“缺陷数据”三个字推定满足所有协议。

若同一工件切块跨训练测试，先重划分；如果阈值在测试集上挑选，重新建立验证协议。只有基线稳定后，才比较纹理/频域/局部表示候选，并用跨批次独立样本证明目标问题。切分漏洞造成的涨点不能作为方法有效证据。
