# 分层知识库

包含 167 张机制卡、208 个PDF文档索引、1708 个去重代码单元的静态接口、95个数据集线索。代码单元包括骨干、模块、工具与训练支持文件，不代表相同数量的独立算法。

- `modules.json`：机制、接入、风险、最小实验与关联文档。
- `papers.json`：文档哈希、题名/主题、页数、原始学术链接与证据边界。
- `code-interfaces.json`：类、构造器、forward签名、依赖、形状示例、断言和静态风险。
- `datasets.json`：95条任务线索、页码与划分注意事项；短链接不当成官方入口。
- 上一版 [书目目录](../catalog.md) 保留321条线索和隔离标记；与本库不可直接相加为模块总数。

检索器默认优先返回机制卡；使用 `--kind paper`、`--kind code`、`--kind dataset` 按层检索。`--inspect ID` 查看完整记录。`--family` 选取机制族。需要完整本机原文或代码时通过 `read_source.py --id ID` 查询可选本机归档；公开安装包不含原始全文和第三方实现。
